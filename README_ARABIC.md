# نظام إدارة الموارد البشرية (HRMS)

## نظرة عامة على المشروع

هذا المشروع عبارة عن نظام إدارة الموارد البشرية متكامل مبني باستخدام:
- **Backend**: Java Spring Boot
- **Frontend**: HTML, CSS, JavaScript
- **Database**: PostgreSQL
- **Build Tool**: Maven

## المميزات الرئيسية

### 1. إدارة الإجازات
- طلب إجازات جديدة
- تتبع حالة الطلبات
- نظام الموافقة للمديرين
- أنواع مختلفة من الإجازات (سنوية، مرضية، طارئة، إلخ)

### 2. لوحة تحكم المديرين
- عرض جميع طلبات الإجازات
- الموافقة أو رفض الطلبات
- إحصائيات مفصلة

### 3. واجهة مستخدم سهلة الاستخدام
- تصميم متجاوب
- واجهة عربية
- سهولة التنقل

## متطلبات النظام

### البرامج المطلوبة:
1. **Java JDK 17** (مرفق مع المشروع)
2. **PostgreSQL 15** (مرفق مع المشروع)
3. **Maven** (مرفق مع المشروع)

## خطوات التثبيت والتشغيل

### الخطوة 1: إعداد قاعدة البيانات
1. قم بتشغيل ملف `postgresql-15.13-1-windows-x64.exe`
2. اتبع خطوات التثبيت
3. قم بإنشاء قاعدة بيانات جديدة باسم `hrms_db`
4. استورد ملف `HRMSDatabase.sql` لإنشاء الجداول

### الخطوة 2: تشغيل Backend
1. افتح موجه الأوامر (Command Prompt)
2. انتقل إلى مجلد المشروع
3. قم بتشغيل الأمر التالي:
```bash
mvn spring-boot:run
```
4. سيتم تشغيل الخادم على المنفذ 8080

### الخطوة 3: تشغيل Frontend
1. افتح ملف `frontend/index.html` في المتصفح
2. أو قم بتشغيل خادم محلي:
```bash
cd frontend
python -m http.server 8000
```

## استكشاف الأخطاء

### مشاكل شائعة:

1. **خطأ في الاتصال بقاعدة البيانات**
   - تأكد من تشغيل PostgreSQL
   - تحقق من إعدادات الاتصال في `application.properties`

2. **خطأ في تشغيل Java**
   - تأكد من تثبيت Java JDK 17
   - تحقق من متغيرات البيئة

3. **مشاكل في Frontend**
   - تأكد من تشغيل Backend أولاً
   - تحقق من إعدادات CORS
