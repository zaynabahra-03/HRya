# 🎤 النظام الصوتي لفهم النوايا - HRMS Voice Intent System

## 📋 نظرة عامة

تم تطوير نظام فهم النوايا الصوتية (NLU) لمشروع HRMS لتمكين المستخدمين من التفاعل مع النظام باستخدام الأوامر الصوتية باللغة العربية.

## 🎉 **ملخص الحالة - جميع الميزات تعمل بالكامل!**

### ✅ **الميزات المكتملة والعاملة:**
1. **إدارة الإجازات** - إنشاء وإدارة طلبات الإجازات
2. **استعلامات الرواتب** - استعلام عن الرواتب والمكافآت  
3. **إدارة الملف الشخصي** - تحديث البيانات الشخصية (محسنة)
4. **تتبع الحضور** - استعلام عن سجلات الحضور
5. **إدارة السياسات** - استعلام عن جميع أنواع السياسات (مضافة حديثاً)

### 🌟 **المميزات:**
- **100% مكتملة وعاملة** - جميع الأوامر الصوتية تعمل
- **دعم اللغتين** - العربية والإنجليزية
- **ذكاء اصطناعي** - فهم النوايا مع مستوى ثقة عالي
- **تكامل كامل** - ربط مباشر مع جميع APIs
- **واجهة اختبار** - اختبار شامل لجميع الميزات

## 🏗️ البنية المعمارية

### البنت الأولى: "صاحبة الصوت والكلام" 🎯
- **IntentRecognitionService**: فهم نوايا المستخدم
- **ArabicLanguageProcessor**: معالجة اللغة العربية
- **VoiceCommandHandler**: معالجة الأوامر الصوتية

### البنت الثانية: "صاحبة الربط والتكامل" 🔗
- **VoiceAPIGateway**: ربط الأوامر الصوتية بـ APIs
- **VoiceResponseBuilder**: إنشاء ردود صوتية
- **VoiceSessionManager**: إدارة جلسات المحادثة

### البنت الثالثة: "صاحبة الواجهة والتجربة" 🎨
- **VoiceUIComponents**: مكونات واجهة المستخدم
- **VoiceTestingDashboard**: لوحة اختبار النظام
- **VoiceDocumentation**: التوثيق والأمثلة

## 🚀 كيفية الاستخدام

### 1. فهم نية المستخدم

```bash
# فهم نية المستخدم بالعربية
POST /api/voice/intent/arabic
{
  "arabicText": "أريد إجازة غداً"
}

# النتيجة المتوقعة
{
  "success": true,
  "message": "تم فهم النية بنجاح",
  "data": {
    "intent": "LEAVE_REQUEST",
    "confidence": 0.9,
    "actionType": "LEAVE_REQUEST",
    "targetAPI": "api/leave-requests",
    "confirmationMessage": "طلب إجازة",
    "isConfirmed": true,
    "parameters": "date: tomorrow"
  }
}
```

### 2. معالجة أمر صوتي

```bash
# معالجة أمر صوتي
POST /api/voice/command
{
  "voiceCommand": "أريد إجازة غداً",
  "userId": 123
}

# النتيجة المتوقعة
{
  "success": true,
  "message": "تم معالجة الأمر الصوتي بنجاح",
  "data": {
    "isUnderstood": true,
    "recognizedIntent": "LEAVE_REQUEST",
    "confidence": 0.9,
    "confirmationMessage": "هل تريد تأكيد طلب الإجازة؟",
    "extractedParameters": "date: tomorrow",
    "suggestedAction": "LEAVE_REQUEST"
  }
}
```

### 3. تنظيف النص العربي

```bash
# تنظيف النص العربي
POST /api/voice/text/clean
{
  "text": "أريد إجازة غداً @#$%"
}

# النتيجة المتوقعة
{
  "success": true,
  "message": "تم تنظيف النص بنجاح",
  "data": "أريد إجازة غداً"
}
```

### 4. استخراج الكلمات المفتاحية

```bash
# استخراج الكلمات المفتاحية
POST /api/voice/text/keywords
{
  "text": "أريد إجازة غداً"
}

# النتيجة المتوقعة
{
  "success": true,
  "message": "تم استخراج 2 كلمة مفتاحية",
  "data": ["إجازة", "غداً"]
}
```

### 5. البحث عن الكلمات المرادفة

```bash
# البحث عن الكلمات المرادفة
GET /api/voice/synonyms/إجازة

# النتيجة المتوقعة
{
  "success": true,
  "message": "تم العثور على 4 كلمات مرادفة",
  "data": ["عطلة", "غياب", "راحة", "إستراحة"]
}
```
